# json_reading

Initial VS Code extension scaffold for json-reading.

## Features

Run **Hello World** from the Command Palette to display a greeting.

## Development

- Run `npm install` to install dependencies.
- Run `npm run compile` to build the extension.
- Press **F5** to launch an Extension Development Host.
- Run `npm test` to run the sample extension test.

See [vsc-extension-quickstart.md](vsc-extension-quickstart.md) for more details.
